Exam Details

The Idaho HVAC Specialty Journeyman exam is part of the state licensing process administered through the Idaho Division of Occupational and Professional Licenses. Candidates must follow the application and examination process established by the Division. The application path depends on the candidate’s selected specialty and qualification method.

Idaho’s HVAC exam bulletin identifies multiple HVAC specialty journeyman examinations. These include specialty exams for hearth, waste oil, and fuel gas piping. The published time limits differ by specialty. The HVAC Hearth Specialty Journeyman exam is listed as a 3-hour exam, while the HVAC Waste Oil Specialty Journeyman exam and HVAC Fuel Gas Piping Specialty Journeyman exam are listed as 2-hour exams. Candidates should select the exam that matches the specialty license they are pursuing.

The minimum passing score for the Idaho HVAC specialty journeyman exams is 70%. The exam bulletin identifies the HVAC exam fee as $75, and that fee is non-refundable. The exam is administered by computer, and candidates are expected to follow all check-in, identification, reference-book, and testing-room requirements.

The question format includes four-option multiple-choice questions, and the bulletin also identifies True/False questions. Exam questions are based on approved reference material, applicable code knowledge, and specialty-level trade knowledge. Candidates should answer according to the approved reference and Idaho exam expectations rather than relying only on field habit or informal jobsite practices.

The International Fuel Gas Code, 2018 is the book included with this rental package. It is especially useful for students reviewing fuel gas systems and related specialty work. Open Book Test

The Idaho HVAC specialty journeyman exams are open book. Candidates are responsible for bringing their own approved reference materials to the testing site. The Division’s exam instructions state that candidates must use approved references and that code books and reference books are not provided at the exam location.

Open-book testing changes the way students should prepare. Instead of trying to memorize every code section, students should focus on learning how the book is arranged and how to find information quickly. A timed open-book exam requires both knowledge and speed. The student must understand enough about the topic to know where to look, then confirm the answer using the approved reference.

Students may prepare their references according to the rules provided by the Division. Highlighting, tabs, and notes are allowed, but loose paper in the reference material is not allowed. Candidates should keep reference preparation clean, organized, and compliant with exam-room rules. Electronic devices, phones, and unapproved materials are not allowed in the testing room.

This package supports open-book preparation by pairing the rental code book with course access. Students can use the course to structure their review and use the book to practice finding answers. The best study habits for this exam include repeated code navigation, careful reading of definitions, reviewing exceptions, and learning to identify which chapter or section applies to a question.

Licensing Steps

The Idaho HVAC Specialty Journeyman licensing process begins with selecting the correct specialty license path and submitting the required application through the Idaho Division of Occupational and Professional Licenses. The state’s application materials recognize education and examination pathways for specialty journeyman applicants, along with required supervised specialty HVAC work experience.

For the education pathway, the application identifies completion of 60 hours of education in fuel gas code and piping installation methods, along with work verification showing 2,000 hours of supervised specialty HVAC installation work. For the examination pathway, the application identifies passing the board-approved examination after application approval, along with work verification showing 2,000 hours of supervised specialty HVAC installation work.

After the application is approved, the candidate receives examination information and may proceed with the scheduling process. Once scheduled, the candidate should prepare using the approved reference material, follow the exam instructions, and bring acceptable identification and approved books to the test site.

A practical licensing plan includes reviewing eligibility, gathering work verification documents, completing the application, receiving exam approval, studying with the correct code reference, taking the exam, and completing any remaining licensing requirements established by the Division. Test Information and Study Materials

The International Fuel Gas Code, 2018 should be used actively during preparation. Students should become familiar with the table of contents, chapter organization, definitions, key tables, exceptions, and index. A good study session should include reading a section, identifying the rule being explained, and then practicing how to return to that rule quickly.

Important fuel gas study areas may include fuel gas piping systems, pipe sizing, appliance installation, combustion air, venting, chimneys and vents, gas utilization equipment, connectors, shutoff valves, testing, and general safety requirements. Students should also review definitions carefully because code questions often depend on the exact meaning of a term.

For open-book exam preparation, students should practice the “find-and-confirm” method. First, identify the subject of the question. Next, decide which chapter or section is most likely to contain the answer. Then locate the code language and confirm the exact requirement. This approach helps reduce guessing and improves time management.

Tabs and highlighting can be useful when done carefully. Students should mark major chapters, frequently used tables, definitions, venting sections, combustion air sections, and other high-value areas. Notes should be clear and compliant with exam rules. Loose paper should not be placed inside the book.

The course access included with this package helps create a more consistent study routine. Students can use the online structure to review material in smaller sessions, return to difficult topics, and build code-navigation confidence before exam day. This is especially helpful for working HVAC professionals who need to study around job schedules, service calls, installations, and family responsibilities.

On exam day, students should arrive prepared with approved references, acceptable identification, and a clear understanding of the testing rules. Since the exam is timed, pacing matters. Students should avoid getting stuck too long on one question. A strong strategy is to answer familiar questions first, use the code book efficiently, and return to harder questions after building momentum.
