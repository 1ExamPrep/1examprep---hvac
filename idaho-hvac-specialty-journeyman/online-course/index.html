Exam Details

The Idaho HVAC Specialty Journeyman exam is part of the state licensing process administered through the Idaho Division of Occupational and Professional Licenses. Candidates must follow the state application and examination process before testing. The exact exam selected depends on the specialty category the applicant is pursuing.

Idaho’s HVAC exam materials identify multiple specialty journeyman examinations, including HVAC Hearth Specialty Journeyman, HVAC Waste Oil Specialty Journeyman, and HVAC Fuel Gas Piping Specialty Journeyman. These exams are specialty-specific and do not all have the same time limits. The HVAC Hearth Specialty Journeyman exam is listed as a 3-hour exam. The HVAC Waste Oil Specialty Journeyman exam and HVAC Fuel Gas Piping Specialty Journeyman exam are listed as 2-hour exams.

The minimum passing score for Idaho HVAC specialty journeyman exams is 70%. Idaho’s HVAC exam bulletin identifies the HVAC exam fee as $75, and the fee is non-refundable. Exams are administered by computer, and candidates must follow all check-in, identification, reference-book, and testing-room rules.

The exam format includes four-option multiple-choice questions, and Idaho’s HVAC exam bulletin also identifies True/False questions. Some journeyman-level testing may include fill-in-the-blank questions. Because the exam is based on approved references, code knowledge, and specialty-level trade understanding, candidates should prepare by studying the book directly and practicing how to locate answers quickly.

The International Fuel Gas Code, 2018 is the code book provided for this preparation product. It is especially important for fuel gas piping and related specialty journeyman topics. Students should study the code book with a practical exam mindset, paying attention to chapter structure, definitions, tables, exceptions, and safety requirements.

Open Book Test

The Idaho HVAC specialty journeyman exams are open book. Candidates are responsible for bringing their own approved reference materials to the testing site. Code books and reference books are not provided at the exam location. Because approved references may be used during the test, preparation should include repeated practice with the exact book used for studying.

Open-book exams require a different strategy than closed-book exams. Students should still understand the material, but they also need to know how to use the reference efficiently. A candidate who spends too much time searching for every answer may lose valuable testing time. Strong preparation includes learning the table of contents, chapter names, definitions, key tables, important exceptions, and the index.

The best open-book test strategy is a “find and confirm” approach. First, identify the topic in the question. Next, determine which section of the code most likely applies. Then use the reference to confirm the exact requirement before selecting the answer. This method helps students avoid relying only on memory or jobsite habits, which may not always match the code language used on the exam.

Students may prepare approved references according to state testing rules. Highlighting, tabs, and notes may be allowed when done within the testing requirements. Loose paper is not allowed in the reference material. Electronic devices, phones, unauthorized notes, and unapproved materials are not allowed in the testing room. Candidates should prepare their book in a clean, organized way that supports faster navigation without violating exam rules.

This online exam prep course supports open-book preparation by helping students study the code as a working reference. The purpose is not just to read the book once. The purpose is to build comfort with locating information, recognizing common topic areas, and using the reference under timed conditions.

Licensing Steps

The Idaho HVAC Specialty Journeyman licensing process begins with choosing the specialty license path that matches the work the candidate intends to perform. Candidates should review the state application requirements and confirm that they are applying for the correct specialty category before preparing for the exam.

Idaho’s specialty journeyman application materials identify an education pathway and an examination pathway. The education pathway includes completion of 60 hours of education in fuel gas code and piping installation methods, along with work verification showing 2,000 hours of supervised specialty HVAC installation work. The examination pathway includes passing the board-approved examination after application approval, along with work verification showing 2,000 hours of supervised specialty HVAC installation work.

After the application is submitted and approved, the candidate receives examination information and can move forward with scheduling. Once the exam is scheduled, the student should prepare with the approved reference material, review the specialty-specific exam expectations, and practice using the code book as it will be used on test day.

A practical preparation path includes confirming eligibility, submitting the application, receiving exam approval, scheduling the exam, studying with the International Fuel Gas Code, 2018, preparing the reference according to testing rules, taking the exam, and completing any remaining licensing steps required by the Division. Test Information and Study Materials

Students preparing for the Idaho HVAC Specialty Journeyman exam should use the International Fuel Gas Code, 2018 actively throughout the study process. The book should become familiar before exam day. Students should know where to find definitions, general regulations, gas piping requirements, appliance installation provisions, combustion air rules, venting requirements, and important tables.

Fuel gas exam preparation should include reviewing pipe sizing concepts, gas appliance installation rules, venting methods, combustion air requirements, connector limitations, shutoff valve requirements, pressure testing, equipment clearances, chimneys and vents, and safety-related provisions. Students should also pay close attention to exceptions and conditions because code questions often turn on a small phrase or limitation.

Definitions are especially important. Many code questions depend on understanding what a term means before applying a rule. Students should spend time reviewing definitions and learning how the code uses specific words. A question may appear simple, but the correct answer may depend on whether the system, appliance, vent, connector, or piping condition fits the exact code definition.

This online course helps students organize their preparation into a more manageable study routine. Instead of trying to absorb the entire code at once, students can review important topics in smaller sections, return to difficult areas, and build confidence over time. This approach is useful for busy HVAC professionals who need to balance exam preparation with work schedules, service calls, installations, and family responsibilities.

A strong study plan should include reading, review, and practice. Reading helps introduce the material. Review helps reinforce it. Practice helps students build speed and accuracy. For an open-book exam, students should practice locating answers in the code book repeatedly. The more familiar the book becomes, the easier it is to use during timed testing.

Students should also practice pacing. During the exam, it is important not to spend too long on one question. A useful strategy is to answer questions you know, use the code book to confirm questions that require exact language, and return to harder questions after completing the easier ones. Good pacing helps protect time for the entire exam.
