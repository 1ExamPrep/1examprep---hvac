### Open Book Test

The Idaho HVAC specialty journeyman exams are open book. Candidates are responsible for bringing their own approved reference materials to the testing site. Code books and reference books are not provided at the exam location. Because approved references may be used during the test, preparation should include repeated practice with the exact book used for studying.

Open-book exams require a different strategy than closed-book exams. Students should still understand the material, but they also need to know how to use the reference efficiently. A candidate who spends too much time searching for every answer may lose valuable testing time. Strong preparation includes learning the table of contents, chapter names, definitions, key tables, important exceptions, and the index.

The best open-book test strategy is a “find and confirm” approach. First, identify the topic in the question. Next, determine which section of the code most likely applies. Then use the reference to confirm the exact requirement before selecting the answer. This method helps students avoid relying only on memory or jobsite habits, which may not always match the code language used on the exam.

Students may prepare approved references according to state testing rules. Highlighting, tabs, and notes may be allowed when done within the testing requirements. Loose paper is not allowed in the reference material. Electronic devices, phones, unauthorized notes, and unapproved materials are not allowed in the testing room. Candidates should prepare their book in a clean, organized way that supports faster navigation without violating exam rules.
