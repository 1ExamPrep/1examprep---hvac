How does the Class C HVACR Contractor exam work?

The Class C HVACR Contractor license comes from the Arkansas HVACR Licensing Board (Department of Labor and Licensing). Prov gives the exam. The board approves your application first; then you schedule the exam and bring only the references the candidate bulletin allows.

  • Arkansas HVACR licenses run from Class A to Class E; Class A has no limit on BTUH or horsepower.
  • Prov proctors the Arkansas HVACR exams, and the board must approve you before you can sit for one.
  • Arkansas has no reciprocal HVACR licensing agreements with other states.
