Test Information and Study Materials

Effective preparation combines HVAC trade review, code navigation, standards study, and repeated use of the references. Passive reading is less useful than locating information, applying it to questions, and reviewing errors.

Begin with HVAC fundamentals. Review heating and cooling principles, system components, equipment functions, airflow, ventilation, ductwork, controls, and installation concepts. A strong foundation makes formal code requirements easier to understand.

Use HVAC Basics for Contractors to strengthen trade knowledge. Focus on how systems operate, how components work together, and how installation decisions affect performance, comfort, and reliability.

For mechanical code preparation, become familiar with the structure of the International Mechanical Code. Review the table of contents, chapters, definitions, sections, tables, exceptions, and cross-references.

Definitions deserve careful attention because technical terms can have precise meanings. A question may depend on the exact use of a term, so candidates should review definitions together with the sections where those terms apply.

Use the SMACNA Residential Comfort System Installation Standards Manual to review residential ductwork, airflow, installation quality, connections, support, sealing, and system performance principles included in the manual.

Organize study sessions by topic. One session may focus on ventilation, while another covers ductwork, equipment, exhaust, combustion air, clearances, system components, or residential comfort installation.

After reviewing a topic, answer practice questions and locate the supporting information in the books. When a question is missed, determine whether the error came from weak trade knowledge, poor reference selection, misunderstanding a code provision, or misreading the question.

Pay close attention to words such as “minimum,” “maximum,” “required,” “permitted,” “except,” and “not.” These words can change the correct response. Read every answer choice before selecting an answer.

During final preparation, use mixed-topic practice that requires switching between trade knowledge, mechanical code, and installation standards. This helps reveal weak areas and strengthens your ability to select the correct reference efficiently.
